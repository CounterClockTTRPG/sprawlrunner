# SPRAWLRUNNER -- the spoken lines, and who speaks them.
#
# One line per recording, read by scripts/assets.sh, which drives ../assetgen
# (project `sprawlrunner`) and writes assets/voice/<name>.ogg. Each voice is an
# assetgen character holding the model, voice, emotion and pace, so every line
# a contact says sounds like the same person:
#
#   assetgen project voice list        (with ASSETGEN_PROJECT=sprawlrunner)
#
# Format, pipe-separated:
#
#   name | voice | text
#
#   name    greet-<contact id>-<index into ContactDef.Greetings>. PlaceScreen
#           plays the one it shows.
#   voice   the assetgen character.
#   text    exactly the line in Tables.Contacts. The self-check compares them,
#           so editing a greeting there without here (and regenerating) fails.
