# SPRAWLRUNNER -- the pictures, and how to ask for them.
#
# One line per picture, read by scripts/assets.sh, which drives ../assetgen
# (project `sprawlrunner`) and writes assets/art/<name>.webp at the size the
# game draws it. The game loads them by name through `Assets.Picture` and
# draws its own procedural art for any that are missing, so nothing here is
# needed to build, run or check the game.
#
# Format, pipe-separated:
#
#   name | aspect | prompt
#
#   name    the file written, and what the game asks for. Stable: the self-check
#           ties these to the tables (contact-<id>, hire-<id>, boss-<faction>,
#           site-<style>), so renaming one here without the table breaks it.
#   aspect  passed to the image model. Portraits are 1:1 and drawn cropped to
#           their panel; banners are 16:9 (the largest flux-1.1-pro offers) and drawn
#           cropped to a strip across the top of the briefing; the title
#           art is 16:9 and fills the screen. `1:1 < hire-ox` paints over
#           another picture (image-to-image on flux-dev), to keep a face.
#   prompt  what the picture is. The project's image style (noir, neon rim
#           light, no text) is appended by assetgen, so this never says how it
#           should look -- except the contact's accent colour, which matches the
#           colour the interface already uses for them.
